# TreeWatch Township

A location-aware public tree-safety reporting and township response prototype.

## Run locally

This is a static single-page application. Open `index.html` in a browser or serve this repository with any static web server. No build step or package installation is required.

For browser geolocation, use HTTPS or localhost and allow location access.

## Prototype features

- Resident Smart Scan & Report flow with guided evidence capture.
- Neighborhood safety map with tree markers and caution zones.
- Location-based weather information.
- My Reports status timeline.
- Township handler dashboard with risk ranking, storm re-ranking, triage, and arborist escalation.

## Important scope notes

This is a demonstration prototype. Risk scoring is rule-based and simulated, not a trained AI diagnosis or certified arboricultural assessment. Reports and handler actions are stored in browser localStorage and are not synchronised between devices. Production use would require a secure shared backend, authentication, protected media storage, and professional validation.

TreeWatch supports prioritisation and communication; it does not replace qualified arborists or emergency services.
